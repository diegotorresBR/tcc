	\chapter{Definições Básicas}
	Quando queremos guardar um registro de um evento de que vivenciamos, geralmente registramos isso através de fotos. E esse processo é feito através de algum dispositivo(ex. Cameras) que captura a fonte de luz da cena do mundo físico e da "refletãncia" da luz dos objetos na mesma. Após isso, é necessário descrever os objetos da cena e representa-los em alguma estrutura de forma que armazene as informações de posicão do elemento da imagem e da cor associada a ela, para o computador.
	%Transformar dados em Imagens é basicamente a definição de Computação Gráfica. Utiliza-se técnicas e métodos para essa transformação e, para isto, utiliza-se um computador. Existem diversas áreas de estudo dentro desse campo de pesquisa tais como Processamento De Imagens, Visão Computacional, Visualização, entre outras. 
	Para exemplificar, vamos olhar para uma fotografia em preto e branco. Nesse modelo temos:
	- O recorte da foto, um retângulo, que iremos chamar de conjunto U, e por ser retangular temos $U \subset R^2$.
	- Uma tonalidade de cinza associada a cada elemento do conjunto U. Essa tonalidade está no intervalo [0,1], onde 0 representa o preto e 1 o branco. Iremos chamar esse conjunto de intensidades de cinza de V
	\newline Dessa forma, temos:\newline
	
	
	Imagem
	
	Para uma imagem monocromátca: \newline
	$$f:  \mathcal{U} \subset R^2 \to \mathcal{V}$$
	$f$ com coordenadas $(x,y) \in R^2$
	
	U é domínio da Imagem(exemplo uma foto 800x600 px)
	
	Quando aplicado um ponto $f(x,y)$(ou seja, os valores de $\mathcal{V}$), dentro de um intervalo [0,L], obtemos o nível de intensidade, ou nivel de cinza
	
	Para imagens coloridas temos $f: U \to R^3$, onde podemos escrever $f_1(x,y), f_2(x,y), f_3(x,y)$, de modo que cada $f_i$ é uma imagem monocromática(chamadas de componentes de cor)
	
	
	
	Amplitude de f é chamada de nivel de cinza(intensidade) aplicada no ponto
	
	Quando (x,y) e f(x,y) são limitadas é chamada de Imagem digital
	
	Processamento Digital é qunado o mesmo é feito por um computador
	
	Visão computacional é quanda a entrada e saída são imagens
	
	Niveis. Baixo: pré-processamento para reduzir ruído
	
	Médio: separação de imagens em regiões para classificação. As saídas são atribuĩdas. Extraídas das imgagens
	
	Formação de Imagen
	
	f: A --> R²
	f: R² --> R⁺
	(x,y) --> z
	
	Componentes
	
	i(x,y) quantidade de iluminação que incide na cena
	r(x,y) quantidade de iluminação refletida pelos objetos na cena
	
	f(x, y) = i(x,y) . r(x,y) produto vetorial
	s.a 0 < i(x,y) < infinito
	0 < r(x,y) < 1
	
	obs: 0 é absorção total e 1é relfetancia total
	
	Intensidade de Imagem(Monocromática)
	l = f(x0, y0)
	(L_min <= l <= Lmax) > 0
	
	[L_min, L_max] - escala de cinza
	deslocamento: [0, L-1]
	l=0 é considerado preto
	l=L-1 branco na escala de cinza
