	\chapter{Definições Básicas}
	Quando queremos guardar um registro de um evento que vivenciamos, geralmente registramos isso através de fotos. E esse processo é feito através de algum dispositivo (ex. câmeras) que captura a fonte de luz da cena do mundo físico e da "refletância" da luz dos objetos na mesma. Após isso, é necessário descrever os objetos da cena e representá-los em alguma estrutura de forma que armazene as informações de posição do elemento da imagem e da cor associada a ela, para o computador.
	%Transformar dados em Imagens é basicamente a definição de Computação Gráfica. Utiliza-se técnicas e métodos para essa transformação e, para isto, utiliza-se um computador. Existem diversas áreas de estudo dentro desse campo de pesquisa tais como Processamento De Imagens, Visão Computacional, Visualização, entre outras. 
	Para exemplificar, vamos olhar para uma fotografia em escala de cinza. 
	
	\begin{figure}[H]
		\centering
		\includegraphics[width=0.5\linewidth]{arara_cinza.jpg}
		\caption{Exemplo de Imagem em escala de cinza}
		\label{fig:placeholder}
	\end{figure}
	
	Nesse modelo temos:
	- O recorte da foto, um retângulo, que iremos chamar de conjunto U, e por ser retangular temos $U \subset R^2$.
	- Uma tonalidade de cinza associada a cada elemento do conjunto U. Essa tonalidade está no intervalo [0,1], onde 0 representa o preto e 1 o branco. Iremos chamar esse conjunto de intensidades de cinza de V
	\newline Dessa forma, temos:\newline
	
	
	\section{Imagem}
	
	Para uma imagem monocromátca: \newline
	$$f:  \mathcal{U} \subset R^2 \to \mathcal{V}$$
	$f$ com coordenadas $(x,y) \in R^2$
	
	U é domínio da Imagem(exemplo uma foto 800x600 px)
	
	Quando aplicado um ponto $f(x,y)$(ou seja, os valores de $\mathcal{V}$), dentro de um intervalo [0,L], obtemos o nível de intensidade, ou nivel de cinza
	
	Para imagens coloridas temos $f: U \to R^3$, onde podemos escrever $f_1(x,y), f_2(x,y), f_3(x,y)$, de modo que cada $f_i$ é uma imagem monocromática(chamadas de componentes de cor, g, e que geralmente, as cores monocromáticas seriam: $i_1$ é vermelho, $i_2$ verde e $i_3$ azul, em inglês RGB)
	
	\subsection{Gráfico}
	
	Podemos visualizar uma imagem geometricamente, que chamaremos de $G(f)$, onde:
	$G(f) = \{(x,y,z): (x,y) \in U\}$ e $z=f(x,y)$
	
	Vamos considerar $z$ como altura em cada ponto do dominio.

	\section{Amostragem}
	
	%Amplitude de f é chamada de nivel de cinza(intensidade) aplicada no ponto
	Afim de criar uma imagem digital é necessário converter os dados captados do mundo real para alguma discretização. Um primeiro processo onde essa conversão ocorre é a Amostragem, que consiste em digitalizar os valores das coordenadas $(x,y)$. Definimos U como:
	
	$U = [a,b]$ x $[c,d] = \{(x,y) \in R^2; a<=x<=b$ e $c<=y<=d\}.$
	E iremos discretizar esse retangulo para um reticulado bidimensional.
	
	\begin{figure}[H]
		\centering
		\includegraphics[width=0.5\linewidth]{malha_bidimensional.jpeg}
		\caption{Malha Bidimensional}
		\label{fig:placeholder}
	\end{figure}
	De forma prática, a Amostragem define a resolução(ex: 800x600px) de uma imagem digital, e cada elemento dessa malha, corresnponde a 1 pixel com coordenadas (x,y).
	
	Quando $(x,y)$ e $f(x,y)$ são limitados, é chamada de Imagem digital
	
	Processamento Digital é quando o mesmo é feito por um computador
	
	Visão computacional é quando a entrada e saída são imagens
	
	Níveis. Baixo: pré-processamento para reduzir ruído
	
	Médio: separação de imagens em regiões para classificação. As saídas são atribuídas, extraídas das imagens
	
	Formação de Imagem
	
	\begin{align*}
		f: A &\to \mathbb{R}^2 \\
		f: \mathbb{R}^2 &\to \mathbb{R}^+ \\
		(x,y) &\to z
	\end{align*}
	
	Componentes:
	\begin{itemize}
		\item $i(x,y)$: quantidade de iluminação que incide na cena
		\item $r(x,y)$: quantidade de iluminação refletida pelos objetos na cena
	\end{itemize}
	
	$$f(x, y) = i(x,y) \cdot r(x,y) \quad \text{(produto vetorial)}$$
	\begin{align*}
		\text{s.a. } & 0 < i(x,y) < \infty \\
		& 0 < r(x,y) < 1
	\end{align*}
	
	Obs: $0$ é absorção total e $1$ é refletância total.
	
	Intensidade de Imagem (Monocromática):
	$l = f(x_0, y_0)$
	$$L_{\min} \leq l \leq L_{\max}$$
	
	$[L_{\min}, L_{\max}]$ - escala de cinza
	
	Deslocamento: $[0, L-1]$
	
	$l=0$ é considerado preto
	
	$l=L-1$ é considerado branco na escala de cinza
	
	
	Amostragem:
	
	É a digitalização dos valores das coordenadas.
	
	
	Quantização:
	- Digitalização de $f$.
	- Conversão de ambas as formas em imagem digital.
	
	Imagem Contínua:
	Ex: Amostragem de uma imagem em uma matriz 2D $M \times N$.
	
	Domínio Espacial:
	$x$ e $y$ são as coordenadas, e $z$ é o nível de intensidade.
	
	Representação Numérica:
	$$f(x,y) = \dots$$
	
	Cada elemento da matriz é um pixel.
	
	Origem:
	
	$L = f_{\min} = 2^k$ - intervalo
	
	Assim, assume-se que os níveis de intensidade são igualmente espaçados:
	$$f: \mathbb{Z}^2 \to \mathbb{Z}$$
	
	Saturação: limite superior/inferior de $L$.
	
	Ruído
	
	Contraste = Saturação - Ruído
	
	Bits para armazenar Imagens:
	$$b = M \times N \times k$$
	
	Interpolação:
	
	Redimensionamento de Imagens:
	Consiste em utilizar dados existentes para estimar valores em pontos desconhecidos.
	
	Ex: $500 \times 500 \to 750 \times 750$
	
	- Manter o espaçamento igual.
	- Procurar o nível do pixel mais próximo.
	
	Bilinear:
	Usa os 4 vizinhos mais próximos para estimar $f$:
	$$f(x,y) = ax + by + cxy + d$$
	
	Bicúbica:
	- 16 vizinhos mais próximos.
	- $f(x,y) = \dots$
	
	Vizinhança:
	De forma geral, todo pixel tem 4 vizinhos.
